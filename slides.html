SentinelOps

An autonomous incident commander for the gaps between engineering tools.

The Problem

Bugs die in Slack threads

  • 1Someone reports a bug in Slack. A few reactions. Then silence.
  • 2Filing a ticket is friction — so no one does it.
  • 3Weeks later: a customer escalation. The internal warning is gone.
"Which bugs did we complain about in Slack that never became tickets?"
What SentinelOps Does

A pipeline, not a dashboard

  • 1Detects unresolved complaints in Slack
  • 2Resolves context across Slack, GitHub, Linear, and Gmail
  • 3Reasons about severity and likely root cause
  • 4Drafts or files a ticket — and closes the loop in Slack
Architecture

Safety By Design

No unrestricted bot with API keys

  • 1Draft-only by default — auto-filing requires an explicit policy
  • 2Every action gated by confidence, severity, and evidence thresholds
  • 3Every decision persisted to a real, inspectable audit log
